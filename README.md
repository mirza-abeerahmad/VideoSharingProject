\# Video Sharing Project



\## Day 1 - Repository Hygiene



This project is a full-stack Video Sharing Platform.



\### Tech Stack



\- Frontend: React

\- Backend: Node.js, Express.js

\- Database: MongoDB

\- Authentication: JWT

\- Password Hashing: bcrypt

\- File Upload: Multer

\- Cloud Storage: Cloudinary
